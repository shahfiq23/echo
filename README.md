# Echo

Offline music player for your own audio files. Import MP3 or M4A files from the iPhone Files app; they're stored on the device and play without internet.

Install: open the GitHub Pages link in Safari → Share → Add to Home Screen.

Files: `index.html` (the whole app), `sw.js` (offline cache; bump `VERSION` on every update), `manifest.webmanifest`, `icons/`.
